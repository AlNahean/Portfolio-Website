## The Mess
Five different dashboards. Five different button components. The codebase was a nightmare of conflicting CSS modules and overriding classes.

## The Strategy
Instead of installing an oversized component library like MUI or AntD, I built an internal CLI tool that pulled raw, accessible components (based on Radix UI) directly into the codebases.

## The Result
Developers gained full control over the markup. Delivery speed for new features increased by 30%, and visual consistency was finally achieved across the suite.

One of the primary failures of "Naive RAG" is semantic isolation. When a document is broken into chunks, individual snippets often lose their reference to the main subject. For example, a chunk mentioning "the cooling system" might not contain the word "Nuclear Reactor," leading to a retrieval failure when a user asks about reactor maintenance.

**Contextual Chunk Headers (CCH)** solves this by using an LLM to generate a concise summary of the document and prepending that summary to every single chunk before embedding.

## How the Pipeline Works

The ingestion flow adds a "Global Awareness" step before the vectorization:

1.  **Global Summarization**: The entire document text is passed to a high-speed model (like `gpt-5.4-nano`) to generate a one-sentence "Global Header."
2.  **Chunking**: The document is split using standard recursive splitters.
3.  **Header Injection**: The "Global Header" is prepended to the text of every chunk.
4.  **Contextual Embedding**: We embed the combined `[Header] + [Chunk]` string. This ensures the vector representation is "anchored" to the document's primary subject.

<Callout>
**The Sticky Note Analogy**
Imagine a stack of 1,000 random sentences on a desk. **Naive RAG** is like trying to find a sentence about "efficiency" without knowing if it refers to a car, a furnace, or a worker. **CCH** is like putting a **header sticker** on every single sentence that says: "Regarding the 2024 Tesla Model 3."
</Callout>

```javascript
import fs from 'fs/promises';
import { getDocumentProxy, extractText } from 'unpdf';
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";
import { embedMany, embed, cosineSimilarity, generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import 'dotenv/config';

const CONFIG = {
  pdfPath: './data/AI_Information.pdf',
  embeddingModel: 'text-embedding-3-small',
  generationModel: 'gpt-5.4-nano',
};

const Log = {
  info: (msg) => console.log(`[INFO]  ${msg}`),
  step: (step) => console.log(`\n--- ${step.toUpperCase()} ---`),
  success: (msg) => console.log(`[OK]    ${msg}`),
};

async function runCCHPipeline() {
  try {
    Log.step("Extraction");
    const dataBuffer = await fs.readFile(CONFIG.pdfPath);
    const pdfProxy = await getDocumentProxy(new Uint8Array(dataBuffer));
    const { text: fullText } = await extractText(pdfProxy, { mergePages: true });

    Log.step("Header Generation");
    const { text: globalHeader } = await generateText({
      model: openai(CONFIG.generationModel),
      system: "Identify the main subject of this text for a RAG header. Be very concise.",
      prompt: fullText.slice(0, 3000)
    });
    Log.info(`Global Header: ${globalHeader}`);

    Log.step("Contextual Splitting");
    const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 800, chunkOverlap: 100 });
    const rawChunks = await splitter.splitText(fullText);
    
    // The CCH Magic: Prepend context to every chunk
    const enrichedChunks = rawChunks.map(c => `Subject: ${globalHeader} | Content: ${c}`);

    Log.step("Indexing");
    const { embeddings } = await embedMany({
      model: openai.embedding(CONFIG.embeddingModel),
      values: enrichedChunks,
    });
    const vectorStore = enrichedChunks.map((text, i) => ({ text, embedding: embeddings[i] }));

    Log.step("Retrieval");
    const query = "What are the cooling requirements?";
    const { embedding: queryVector } = await embed({
      model: openai.embedding(CONFIG.embeddingModel),
      value: query,
    });

    const context = vectorStore
      .map(item => ({ text: item.text, similarity: cosineSimilarity(queryVector, item.embedding) }))
      .sort((a, b) => b.similarity - a.similarity)
      .slice(0, 2)
      .map(m => m.text).join("\n\n");

    const { text } = await generateText({
      model: openai(CONFIG.generationModel),
      system: "Answer based on context. Note that each snippet includes document subject metadata.",
      prompt: `Context:\n${context}\n\nQuestion: ${query}`,
    });

    console.log(`\nAI Response:\n${text}`);

  } catch (err) {
    console.error(err);
  }
}

runCCHPipeline();
```

## Summary of Impact

| Metric | Basic Chunking | Contextual Headers |
| :--- | :--- | :--- |
| **Retrieval Robustness** | Moderate | **High** |
| **Semantic Drift** | High | **Low** |
| **Metadata Preservation** | Manual | **Automatic (Inside Vector)** |
| **Embedding Payload** | Smaller | Larger (+ Header Tokens) |

## When to Use This
- **Technical Manuals**: Where specific parts (e.g., "The Bolt") appear in multiple chapters with different meanings.
- **Multilingual RAG**: To keep a constant "topic anchor" across translated documents.
- **Large Knowledge Bases**: When searching across hundreds of PDFs where chunks may look similar without global identifiers.

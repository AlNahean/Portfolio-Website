### How to use this:
1. **Create the file**: Save the code above as `content/docs/components-demo.mdx`.
2. **Register it**: If you have a `meta.json` in `content/docs`, add `components-demo` to the `pages` array.
3. **Verify**: Run `pnpm run dev` and navigate to `/docs/components-demo`.

### Tips for writing MDX in this project:
- **`__raw__` prop**: Any code block you write in MDX automatically gets a copy button because of your `mdx-components.tsx` configuration.
- **Dynamic Imports**: Because you are using a custom registry, you can always drop in a new `<ComponentPreview name="your-component-name" />` as long as it's defined in `src/registry/index.ts` and you've run `pnpm run build:registry`.
- **Styling**: You can combine Tailwind classes with standard MDX tags (e.g., `<div className="flex gap-4">...</div>`) directly within the `.mdx` file.
